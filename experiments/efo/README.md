# EFO：事件保真优化实验包

事件保真（Event Fidelity Optimization, EFO）是"检测 → 连续 k 帧确认 → 业务事件"这条链的评价维度。
它回答一个帧级 mAP 回答不了的问题：**下游事件判得对不对**。

## 为什么需要它

目标检测的验收指标是帧级 mAP。但卒中质控、工业质检、交通事件检测、安防告警，
下游用的都是"连续 k 帧确认"的状态机。帧级指标与事件级正确性之间**没有单调映射**，
按帧级验收会系统性高估系统可靠性。

本包给出三条可证伪的命题，并全部用代码验证。

## 三条命题

| 编号 | 命题 | 闭式解 | 性质 |
|---|---|---|---|
| P1 | 结构性盲区 | 可见时长 < `k_in` 帧 ⇒ 必然漏检；盲区宽度 = `k_in − 1` 帧 | 定义推出，确定性 |
| P2 | 指数放大 | 可见段恰为 k 帧时，事件检出率 = `p^k` | 概率模型 + 实验 |
| P3 | 滞留偏置 | 区间口径 `(m_out − k_in)·Δt`；中心口径 `(m_out − k_in + 1)·Δt` | 定义推出，确定性 |

以本项目配置 `k_in=3, m_out=5, Δt=66.67ms` 为例：

- 盲区 = 2 帧 = **133 ms**
- p=0.95 时事件检出率 = 0.95³ = **0.857**（相对单帧损失 14.3%）
- 滞留时长高估 **+133.3 ms**（区间口径）／**+200.0 ms**（中心口径）

> 注意符号：滞留时长是**被高估**，不是被低估。入画确认延迟 `(k_in−1)·Δt`，
> 离画确认延迟 `m_out·Δt`，后者更大 ⇒ 测量值偏长。

## 目录

```
experiments/efo/
├── core.py                # 数据装载 / 状态机调用 / 事件匹配 / 指标 / 报告
├── exp1_blind_zone.py     # P1 结构性盲区（全枚举，无随机）
├── exp2_amplification.py  # P2 指数放大（2a 合成解析对照 + 2b 真实序列注入）
├── exp3_dwell_bias.py     # P3 滞留偏置（多组 k/m 的闭式解检验）
├── run_all.py             # 总入口，产出 SUMMARY.md
└── out/                   # 产物（json + md），可提交
```

## 运行

在仓库根目录执行：

```bash
python -m experiments.efo.run_all
```

只跑单个：

```bash
python -c "from experiments.efo import exp1_blind_zone as e; e.run()"
```

纯标准库实现，无需 numpy/pandas，Python 3.10+ 即可。
Windows 控制台若报编码错误，先设 `set PYTHONIOENCODING=utf-8`。

## 数据契约

读取 `data/demo/json/{seq}.json`：

```json
{
  "seq": "10_ST0_SE9", "fps": 15.0, "frame_ms": 66.67,
  "frames": [{"frame": 0, "ts_ms": 0.0, "hit": true, "boxes": [{"conf": 0.951}]}]
}
```

状态机只消费 `boxes[].conf` 与帧序，因此实验可完全合成输入。

**与系统同源**：所有实验调用 `app/modules/events/state_machine.py` 的 `generate_events`，
不复制一份实现——否则"实验里测的"与"线上跑的"不是同一个东西，结论不可信。

## 如何接入 1527 帧验证集

当前实验跑在 `data/demo/json` 的两段离线序列上（114 帧 / 294 帧），
它们只够验证方法与量级，**不足以支撑统计结论**。

接入方式：把验证集的逐帧检测结果导出成上面的 JSON 契约，放入
`data/demo/json/`（或改 `core.DATA_DIR`），`list_sequences()` 会自动发现。
届时 exp2b 的事件级 F1 才有统计意义。

## 可引用的产出

运行后 `out/` 下：

- `exp1_blind_zone.{json,md}` — 检出率随可见时长坍缩的表格（按 k 分组）
- `exp2_amplification.{json,md}` — 2a 解析对照 + 2b 真实序列事件 F1 衰减
- `exp3_dwell_bias.{json,md}` — 五组 (k_in, m_out) 的闭式解检验
- `SUMMARY.md` — 一页结论，可直接贴进材料

## 边界（写材料时必须遵守）

1. **P1/P3 是解析结论**，由定义直接推出，实验只是验证实现与该结论一致。
   不要表述为"实验发现"。
2. **P2 的实验部分是注入噪声模型**，不等于真实 INT8 量化误差。
   若未在真实量化模型上验证，必须写"注入模型下的结果"。
3. 当前序列来自演示数据，**不能**据此下任何临床有效性结论。
4. 昇腾/DVPP 相关的吞吐维度**本包未涉及**，不要与 EFO 的正确性结论混为一谈。
